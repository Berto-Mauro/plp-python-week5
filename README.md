# Week 5 Assignment: Countdown, Guessing Game & Loop Patterns

This assignment practices Python `while` and `for` loops, conditionals, counters, and user input.

## Files

* `countdown.py` — Counts down from a number entered by the user and prints "Blast off!".
* `guess_game.py` — Runs a guessing game with hints and an attempt counter.
* `spell_it_out.py` — Prints each letter of a word individually and then numbers each letter.

## What I Learned

* How to use `while` loops for repeated actions.
* How to use `for` loops to work through characters in a word.
* How to use `if`, `elif`, and `else` with loops.
* How to use counters to count attempts and number letters.
* How to use `int()` and `len()` in Python.
